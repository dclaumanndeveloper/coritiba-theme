# Coritiba Theme 🟢⚪

Tema inspirado nas cores do Coritiba Football Club para Visual Studio Code.

## 🎨 Características

- **Tema Dark**: Fundo verde escuro com sintaxe nas cores padrão do VS Code
- **Tema Light**: Fundo branco com elementos verdes do Coritiba
- **Interface**: Cores oficiais do Coritiba (verde #00593f)
- **Sintaxe**: Cores padrão do VS Code para melhor legibilidade
- **Destaque especial**: Tipo `any` do TypeScript em vermelho para alertar sobre má prática

## 📦 Instalação

### Via Marketplace (em breve)
1. Abra o VS Code
2. Vá em Extensions (`Ctrl+Shift+X`)
3. Busque por "Coritiba Theme"
4. Clique em Install

### Via arquivo .vsix
1. Clone este repositório
2. Execute: `vsce package`
3. Instale o arquivo `.vsix` gerado

### Desenvolvimento
1. Clone este repositório
2. Copie a pasta para `%USERPROFILE%\.vscode\extensions\` (Windows)
3. Reinicie o VS Code
4. Vá em `File > Preferences > Color Theme` e selecione "Coritiba Theme" ou "Coritiba Light"

## 📝 Cores do Coritiba

- Verde oficial: `#00593f`
- Verde escuro: `#003d2b`
- Verde claro: `#4caf50`
- Branco: `#ffffff`

## ⚠️ Destaque TypeScript

O tipo `any` aparece em **vermelho com sublinhado** para alertar sobre uso inadequado de tipagem.
